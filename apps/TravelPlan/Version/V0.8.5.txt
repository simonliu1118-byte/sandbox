TravelPlan V0.8.5 - Windows 實機待驗證版
Date: 2026/09/09 (UTC+8)
Baseline: 本工作上傳的 V0.8.4 source；不以舊交接 Markdown 覆蓋 source 行為。

資料安全
- 草稿儲存、刪除旅行、全域設定改為磁碟成功後才提交正式記憶體資料。
- 寫檔使用獨立暫存檔、Sync、Close、Rename，失敗清理暫存檔並保留原資料。
- 同一個可攜式目錄以 Windows mutex 避免兩個程式實例互相覆寫。
- JSON 載入保留缺省設定；解析失敗不改變目前資料。
- 同秒多次備份使用不同檔名，不再覆寫。
- 儲存前提交失焦欄位，檢查旅行日期有效性與多日日期順序。

編輯與 lifecycle
- 維持 NoSelection / View / New / Edit、三 Pane 及 workingTrip 架構。
- 重繪時抑制控制項初始化通知；清單重填時抑制選取事件重入。
- 單日勾選確實標記 dirty；保留 EndDate，不改成開始日。
- 儲存格 editor 不再加入一般表單控制池；使用固定保留 ID。
- 修正第一欄矩形、ListView 到 Pane 的座標轉換及新 editor 被舊 timer 關閉。
- 日期 editor 等待日曆關閉／失焦後再重排；文字 editor 支援 Enter 完成、Esc 放棄該欄。
- 補齊 Tab 導覽及備註 Tab / Shift+Tab 縮排操作。
- 每日 ↑↓ 交換使用者內容，保持日期／Day ID 不動；單日模式不移到隱藏日期。
- 改名的固定餐別視為使用者資料，日期縮短時保留。
- 住宿補出原資料模型已有的台幣金額輸入欄。

檢視／匯出
- 單日 Word 不輸出住宿與其他日期；每日住宿摘要也遵守單日規則。
- 檢視模式補交通、巢狀備註、餐飲、每日備註並量測文字換行高度。
- Word 暫存完成後才替換目標；處理 ZIP 寫入與關閉錯誤。
- 方案名稱也清理路徑非法字元；每日換頁不再產生最後的空白頁。
- 短或損壞 OriginalDate 不再引發切片 panic；時間格式更嚴格。

視覺
- 淺灰畫布、白色卡片、低對比格線與清晰深色文字，保留區塊彩色 accent。
- 字體層級調整；加上最小視窗尺寸，避免密集欄位被過度擠壓。
- 原 icon／歡迎圖引用不變；未提供圖檔時歡迎頁使用文字 fallback。

驗證與界線
- Go 1.23.12：核心測試、race、go vet 通過。
- Windows amd64 GUI 交叉編譯成功；Common Controls v6 manifest 已加入 EXE。
- 本環境未執行 Windows GUI，因此沒有宣稱原生互動、DPI、繪製實機全部通過。
- 本包未附原 assets，EXE 未嵌入原 icon；執行時會讀取原資料夾的 assets。
- OverallNotes 仍在 Trip（所有方案共用），不自行遷移資料模型。
- Google Drive、滑鼠拖曳每日資料仍屬既有未完成範圍，沒有假稱已完成。
