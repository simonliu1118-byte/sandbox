TravelPlan V0.8.0
Date: 2026/09/08

右側 UI lifecycle 重構版

1. 右側拆成三個獨立 Pane：未選取歡迎畫面、檢視模式、編輯模式；三種畫面不再共用同一棵 child HWND。
2. 新增／修改改用 workingTrip 草稿；草稿與正式 store.data.Trips 完全分離。
3. 新增計劃第一次儲存以前不會加入正式 Trips，也不會出現在左側清單。
4. 修改既有計劃時先複製成 workingTrip；取消只丟棄 workingTrip，不再整包 AppData rollback。
5. 儲存時才把 workingTrip 寫回正式資料；若磁碟儲存失敗，正式資料與原選取計劃保持不變。
6. 移除右側 render 流程的 WM_SETREDRAW(FALSE)；改用 Pane 隱藏後排版，完成後 RedrawWindow + RDW_ALLCHILDREN 完整重畫子控制項。
7. 歡迎圖固定留在獨立 empty Pane 的控制池，進入新增／修改時不再拆掉 Bitmap；取消後直接回歡迎 Pane。
8. 每個 Pane 擁有自己的 HWND control pool，避免 Bitmap、檢視按鈕、編輯輸入欄互相重用或殘留。
9. 新增、取消、儲存、修改、切換計劃統一使用 NoSelection / View / New / Edit 四種明確模式。
10. 保留 V0.7.4 左側清單格線、斑馬紋與既有編輯功能；本版不再擴充航班／住宿／每日行程細節。
