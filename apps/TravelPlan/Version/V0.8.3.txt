TravelPlan V0.8.3
Date: 2026/09/09

- 左側旅行清單 Header 底部改由 Header 自身補 1px 系統深灰分隔線。
- 一般單行輸入框改回真正原生 Win32 EDIT 邊框與 COLOR_WINDOW 背景。
- 單行 EDIT 高度依目前字型實際高度計算，只保留少量上下 padding，改善文字視覺垂直置中。
- 左側查詢欄同步改為原生 EDIT 邊框與自然高度。
- 航班／住宿 ListView cell editor 移除過度嚴格的最小高度阻擋，恢復雙擊儲存格編輯。
- 航班編輯表格維持原結構，但移除獨立「跨日」欄；抵達時間直接顯示 (+1) / (-1) 等日期偏移。
- 抵達時間允許輸入例如 15:30 (+1) 進行手動日期偏移修正。
- 航班／住宿 ListView 欄寬改為內容最小寬度 + 彈性欄位分配；視窗縮小到確實放不下時才出現水平 scrollbar。
- ListView 高度依實際資料列數計算；若需要水平 scrollbar，會把 scrollbar 高度納入，避免再產生垂直 scrollbar 或切掉最後一列。
- 歡迎畫面文字再放大一級。
- 檢視模式的航班摘要改成較精簡的「航段｜日期/時間｜航空公司｜航班號｜航線」閱讀格式。
