# momo 一頁式私人查價預覽

可直接輸入關鍵字，自動搜尋 momo 並列出商品名稱、品號、公開展示價與來源；價格預設低至高，可改高至低。使用 Vercel Python / Flask，與 CYWEB 完全分離。

## 本機執行

在 apps/ScraplingProbe/site 資料夾：
1. pip install -r requirements.txt
2. python app.py
3. 在瀏覽器開啟 http://127.0.0.1:8765

## Vercel 預覽部署

- Git repo: simonliu1118-byte/sandbox
- Root Directory: apps/ScraplingProbe/site
- Framework: Other / Flask 自動偵測
- Python: 3.12
- 環境變數 APP_ACCESS_PASSWORD：必須設定私人測試密碼，且不得提交至 Public Git。
- 若 VERCEL 環境未設定密碼，應用回應 503 並拒絕任何查詢。
- 所有測試站頁面均需要 HTTPS Basic Auth，阻止未授權的正常存取；資料庫／登入／商品下單均不存在。
- 本次僅允許獨立 Preview 部署，不合併既有 Draft PR、不改動 CYWEB、不發正式 Release。

## 使用與限制

- 僅單次一般公開 HTTPS 查詢，無登入、代理、CAPTCHA 繞過、重試、購買、排程。
- 每個執行實例最多 20 筆，10 分鐘相同關鍵字快取，兩次不同查詢最少間隔 15 秒（記憶體最佳努力限制）。
- 被站方拒絕後該執行實例暫停查詢 30 分鐘。Serverless 多實例並非全域防濫用；正式上線需要中央限額。
- 來源使用 momo 非正式保證的搜尋介面，可能變動；Vercel 雲端 IP 也可能與 GitHub Actions 不同、遭遇封鎖。必須部署後再實測才可聲稱網站可用。
- 價格為搜尋展示價，非特定規格或結帳價。沒有價格不以 NT$0 代表。
- GitHub Actions Run #22：羅技 M331 實測 2 筆價格；Run #23：咖啡實測 14 筆價格；這是 GitHub Runner 結果，非 Vercel 部署成功證據。

## V0.3.2 — 修正 3m 1530 只顯示一筆

原因：原型強制每一個搜尋字串皆出現在商品標題中，因此刪除 momo 已回傳的相關商品；另外固定只讀取 curPage=1。

- 保留 momo 第一頁回傳的每筆有效品號（最多 20 件），標註「完全符合／型號相關／部分相關／momo 推薦」，不因搜尋字詞不完全一致而刪除；預設按相關程度排列，另有價格排序。
- 增加手動上一頁／下一頁，允許查 1～5 頁，但每次**只**在使用者主動點擊時查單一頁（無自動掃描，不重試阻擋）。
- 10 分鐘快取依「關鍵字+頁碼」保存；兩次不同的查詢最短間隔 15 秒，遇限制暫停 30 分鐘。Vercel 多執行實例不保證全域節流。
- 這份介面可能與官方網頁的個人化、廣告、關鍵字推薦不同；修復「程式自行丟棄」問題不等於保證和官方結果完全相同。

## V0.3.2 Build 2 — 確認 TP 開頭的第三方商品被誤刪

[Run #25](https://github.com/simonliu1118-byte/sandbox/actions/runs/43719323901) 對 `3m 1530` 取得 momo 正式搜尋介面 HTTP 200，`success=true`，6 筆商品、六種有效公開展示價。舊原型只顯示 1 筆，**不是站方少回傳，而是程式誤將非純數字之 `TP...` 3P 商店商品識別碼當成無效資料。**

實際六筆為 `14011391`（NT$259）、`TP00013930000165`（NT$190）、`TP00065910000469`（NT$54）、`TP00052130002280`（NT$406）、`TP00071080000060`（NT$69）、`TP00094060000571`（NT$100）。

修正商品識別碼驗證，明確接受經本站實際回傳的數字碼或 TP+數字碼；第三方商品使用 `goods/GoodsDetail.jsp?i_code=TP...` 連結。保留前一輪的相關程度標示、手動分頁（上限五頁）、費率與阻擋保護。新增使用實際商品代碼與公開展示價的離線回歸測試。

注意：商品價格對應不同包裝入數與尺寸；未來彙整必須歸一化規格／單位，不得因價格最低就誤判相同 SKU。
