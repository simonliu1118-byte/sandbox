# ScraplingProbe Project Rules

- 專案類型：個人技術可行性實驗，Python 3.12、Scrapling。
- 範圍：公開商品頁單次讀取、價格候選值擷取與測試報告；可用於蝦皮、momo、酷澎及允許一般查詢的第三方公開資料服務；不接入任何正式服務。
- 測試不得登入、取得或儲存帳號 Cookie、操作購物車／結帳、使用代理輪換、重試限制回應或處理驗證挑戰。
- 商品價格必須標為「候選值」，未經人工核對不得宣稱為最終實付價。
- GitHub Actions 每個來源只執行單次測試，不對被阻擋的來源重試；報告僅包含必要的公開價格摘要，不保存原始 HTML、HTTP headers 或回應主體。
- 此專案不設定自動排程，不進行正式部署或 Release；若需要擴大資料存取，先確認平台許可及使用者授權。
- 第三方價格來源應保留來源名稱、資料取得時間與商品識別；尚未驗證的價格不可視為最終成交價，商業大量利用須確認來源授權。

- 競品查價採雙軌資料來源：有對應 SKU／規格 ID、名稱及各規格獨立售價者可評估為主要方案（低成本有上限）；**只有商品最低價、最高價或區間的備用來源，一律須在預定長期使用量內持續免費，實際付款金額為零**。
- 備用來源不得依賴一次性試用、註冊贈額、試用到期後付費或按筆收費。若使用每月固定重置的免費配額，必須先確認配額足以涵蓋計畫查價量、無自動付費／超額扣款，且程式達上限即停止，才能列為可採用備用來源。無法證明長期零費用者一律排除正式備用資格。
- 已知需付費的服務即使能提供價格區間，仍可作為技術研究記錄，但**不得**列為正式備用候選。只要完整逐規格售價仍可依主要方案預算另行評估；Octoparse 已因預算限制排除。
