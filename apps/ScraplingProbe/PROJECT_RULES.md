# ScraplingProbe Project Rules

- 專案類型：個人技術可行性實驗，Python 3.12、Scrapling。
- 範圍：公開商品頁單次讀取、價格候選值擷取與測試報告；不接入任何正式服務。
- 測試不得登入、取得或儲存帳號 Cookie、操作購物車／結帳、使用代理輪換、重試限制回應或處理驗證挑戰。
- 商品價格必須標為「候選值」，未經人工核對不得宣稱為最終實付價。
- GitHub Actions 只執行單次測試，報告為匿名化 JSON；不保存原始 HTML、HTTP headers 或回應主體。
- 此專案不設定自動排程，不進行正式部署或 Release；若需要擴大資料存取，先確認平台許可及使用者授權。
