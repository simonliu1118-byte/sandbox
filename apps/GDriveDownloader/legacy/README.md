- [`v1.4.2-visible-debug/`](v1.4.2-visible-debug/)：由 `GoogleDrive影片下載器_v1.4.2_可視除錯版_Windows_x64.zip` 的發行內容還原。

Legacy 內容不得覆蓋目前專案的 C# / .NET 8 / WinForms + WebView2 技術線，也不得重新引入舊版自行解析 Google Drive 畫質的策略。
