# TimecardOCR（打卡鐘每日工時統計）

> 專案版號：V0.1.0（首次導入 sandbox；來源為先前測試的 V2 可攜版）。

這是 Windows 10 / 11 的免安裝本機網頁工具，將紙本打卡卡照片辨識為每日打卡時間，供人工核對後，以每 15 分鐘為一單位計算工時並輸出 Excel。

## 功能

- 正面（1–15 日）與背面（16–31 日）的打卡卡照片上傳。
- 優先使用 Windows 本機 OCR，**不需 API Key**。
- OCR 辨識有疑義時，可自行輸入 Gemini API Key，明確同意後使用雲端 AI 輔助。AI 候選結果需手動確認後才套用。
- 同一日 2 筆打卡時按時間先後計算；4 筆打卡時依先後成對計算、合計實際工作分鐘。
- **當日總分鐘數除以 15 後無條件捨去餘數**：28 分鐘 = 0.25 小時；47 分鐘 = 0.75 小時。
- 匯出 `.xlsx`，顯示日期、起訖時間、原始打卡、每日工時及整月工時加總。

## 啟動

1. 將整個 `apps/TimecardOCR` 資料夾複製到 Windows 電腦。
2. 雙擊 `啟動程式.bat`；本機服務與瀏覽器會開啟 `http://127.0.0.1:18763/`。
3. 上傳照片，辨識後請逐筆核對、修正，再匯出 Excel。
4. 關閉命令視窗即停止本機服務。

僅需 Windows 10 / 11 內建 PowerShell 5.1 與瀏覽器；不需 Python、Node.js。更多操作資訊請參閱 `使用說明.txt`。

## 安全與資料隱私

- 本機 OCR 不會上傳打卡照片；使用 Gemini 時，照片裁切預覽及上傳均須使用者確認。
- 切勿將真實員工照片、API Key、憑證、匯出 Excel 等資料提交到 GitHub 公開儲存庫。
- 本程式尚未在所有 Windows OCR 語言與 Gemini API 設定中做實機驗證；**辨識結果必須人工核對，不能直接作為薪資依據**。
- Gemini 免費額度與模型可用性由 Google 決定，可能有用量限制或費用。
