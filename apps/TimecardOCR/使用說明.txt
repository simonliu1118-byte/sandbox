打卡鐘每日工時統計 － Windows 免安裝可攜版 V0.1.0（源自 V2 原型）（OCR + Gemini AI 補強）
=====================================================================
適用：Windows 10／11 + 系統內建 Windows PowerShell 5.1。
本程式不需要安裝 Python、Node.js 或其他執行環境，也不需系統管理員權限。
雙擊「啟動程式.bat」即可運作，使用瀏覽器操作。

【開始使用】
1. 下載 ZIP，按「全部解壓縮」成資料夾。切勿直接在 ZIP 中開啟 BAT。
2. 雙擊資料夾內「啟動程式.bat」，不要只單獨移動這支 BAT。
3. 會開啟命令視窗及瀏覽器：http://127.0.0.1:18763/
4. 選擇年份月份、上傳 1–15 日正面與 16–31 日背面照片。
5. 先按「開始離線 OCR 辨識」，下方逐日檢查打卡時間是否正確。
6. 如果 OCR 讀不到／讀錯，可手動修改；或依下方【AI 補強】使用 Gemini。
7. 校正後勾選「已核對」，按「下載 Excel（.xlsx）」。
8. 關掉啟動程式的命令視窗，即結束本機服務。

【Gemini AI 補強－完全選用】
1. 以瀏覽器開啟 https://aistudio.google.com/apikey 取得 Google Gemini API Key。
2. 在「AI 辨識補強」輸入 Key，預設模型 Gemini 3.5 Flash-Lite。
3. 勾選傳送照片到 Google 的同意選項。
4. 在照片下方先按「預覽 AI 上傳範圍」，確認只含日期與打卡表格。
5. 點「AI 辨識此張（需同意）」，需有網路。每張分別點選。
6. AI 辨識後會顯示日期與候選時間；勾選要套用的日期，再按套用。
7. 原有且完整的日期預設不勾選；已人工核對資料不會不經提醒就覆蓋。
8. AI 判讀也可能出錯，最後仍請核對原照片，勾選「已核對」。

【隱私及費用】
* 離線 OCR 的照片只在電腦本機處理，不上傳網路。
* AI 使用時才向 Google Gemini 官方 API 傳送該照片中經裁切的打卡表格。
  裁切設計用來排除上方姓名／單位；請先預覽，避免意外包含敏感資料。
* API Key 僅暫存於目前瀏覽器欄位及當次傳輸的記憶體；程式不儲存到檔案。
  關閉分頁／程式後需重新輸入。不要分享 Key 或螢幕截圖中的 Key。
* Google API 免費配額不是無限制；可用模型、限制、收費規則以 Google 公告為準。
  免費方案傳送的資料可能依 Google 的資料政策用於改善產品。
  上傳員工打卡紀錄前請確認已取得必要的公司／員工授權。

【工時計算】
* 每天 2 筆：依先後計算時間差，不跨日。輸入順序不重要。
* 每天 4 筆：依先後排序、兩兩配對，加總當天工作分鐘，不跨日。
* 將當日總分鐘數除以 15，無條件捨去餘數；15 分鐘 = 0.25 小時。
  例如 28 分鐘算 0.25 小時；47 分鐘算 0.75 小時。
* 單筆、三筆、不合法時間無法配對，標記為待補正，不強制算成工時。
* Excel 顯示日期、最早打卡、最晚打卡、原始打卡內容、實際分鐘、
  計算分鐘、工時（十進位小時）、備註與整月合計。
* Excel 中 I–L 欄是標準時間格式，可以修改後由公式重新計算。

【若啟動失敗】
* 不要在 ZIP 壓縮視窗中直接雙擊 BAT；先完整解壓縮。
* 部分公司電腦有限制 PowerShell 或 Windows OCR 語言元件，需資訊人員協助。
* 若看不到網頁，先關閉舊的命令視窗再重開。
* 若離線 OCR 不可用，不影響手動輸入、AI 補強或 Excel 匯出。
* 若 AI 報 401/403，檢查 Key；429 是用量限制；404 可切換模型。
* 仍有問題請把命令視窗與網頁錯誤畫面回傳以協助排除。

【檔案清單】
啟動程式.bat  ：點兩下啟動
server.ps1    ：本機網站服務
ocr.ps1       ：Windows 離線 OCR
Gemini.ps1    ：選用的雲端 AI 辨識（實際檔名 gemini.ps1）
index.html / app.js / ai.js ：瀏覽器介面、工時計算、Excel、AI 比對

注意：此程式尚未在所有 Windows/OCR 語言設定上完成實機測試；
      Gemini API 需要使用者自己的金鑰，發行者沒有替你實際呼叫雲端服務。
