① 設定月份及上傳照片

照片範例為正面 1～15 日、背面 16～31 日。每張圖片都可以指定「正面 / 背面」，必要時調整裁切格線。若不使用照片，也可直接在下方逐日輸入打卡時間。離線 OCR 執行失敗可改用下方的 AI 備援按鈕。

準備就緒。請選照片，或直接在下方輸入打卡時間。

② AI 辨識補強（選用，預設不啟用）

離線 OCR 看不清或辨識錯誤時才使用。請先在上方選好照片的正反面、調整裁切範圍；照片列下方會出現「預覽 AI 上傳範圍」及「AI 辨識此張」按鈕。只上傳打卡表格區域，不上傳卡片上方的姓名／單位欄位。使用 AI 需要網路與有效的 Gemini API Key，免費額度及可用性以 Google 帳號實際狀態為準。

AI 回傳的是候選結果，不會自動覆寫任何打卡時間。使用前請預覽裁切圖並比對原始照片；未經確認的辨識不應作為薪資計算依據。每次重新開啟程式都要重新輸入 API Key。

③ 核對打卡時間、計算工時

每格填入同一天的 2 筆或 4 筆打卡時間，用逗號分隔，例如 12:50, 13:45。順序可顛倒，程式會自動排序；4 筆依時間先後分成兩組計算。每日總分鐘數不足 15 分鐘的部分捨去，例如 28 分鐘 = 0.25 小時，47 分鐘 = 0.75 小時。不跨日。

④ 使用提醒

本程式不需要 Python。離線 OCR 不需網路或 API Key；僅在你主動使用 AI 補強辨識時需要網路與 API Key。點陣式印字、傾斜及反光可能辨識錯誤，務必對照原照片核對；不會把不完整或格式錯誤的打卡硬算成工時。按下「已核對」表示你已自行對照照片。離線 OCR 是否可用取決於 Windows 已安裝的 OCR 語言元件；若系統不支援，可繼續手動輸入並輸出 Excel。
